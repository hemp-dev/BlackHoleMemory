# Конфигурация BlackHoleMemory

Конфигурация BlackHoleMemory построена на принципах безопасности, явного управления параметрами и защиты приватных данных оператора. Проектные схемы и дефолты хранятся в директории `config/`, а локальные настройки — в переменных окружения или `.env`.

---

## 1. Переменные окружения

Все переменные окружения BlackHoleMemory имеют префикс `BHM_`. Ключи для внешних провайдеров LLM считываются из окружения или файла `~/.bhm/.env`.

| Переменная | Описание | Значение по умолчанию |
| --- | --- | --- |
| `BHM_APP_NAME` | Название экземпляра приложения | `BlackHoleMemory` |
| `BHM_APP_ENV` | Окружение запуска (`dev`, `production`) | `dev` |
| `BHM_HOST` | IP-адрес привязки API-сервера | `127.0.0.1` |
| `BHM_PORT` | Порт API-сервера | `8000` |
| `BHM_MEMORY_STORE_MODE` | Режим работы хранилища master | `sqlite-authoritative` |
| `BHM_QDRANT_URL` | URL подключения к Qdrant | `http://127.0.0.1:6333` |
| `BHM_QDRANT_COLLECTION` | Имя коллекции векторных проекций | `blackholememory` |
| `BHM_QDRANT_API_KEY` | API-ключ Qdrant (если требуется) | `""` |
| `BHM_CONTEXT_PROFILE` | Профиль контекста (`standard`, `compact`, `deep`) | `standard` |
| `OPENAI_API_KEY` | Ключ доступа для эмбеддингов/LLM | `""` |
| `OPENAI_BASE_URL` | Базовый URL для OpenAI-совместимого API | `http://127.0.0.1:11434/v1` (локальный LLM) |
| `OPENAI_MODEL` | Модель для обработки контекста | `qwen2.5-coder-7b-instruct` |

---

## 2. Манифесты и файлы конфигурации (`config/`)

В директории `config/` хранятся канонические схемы проекта:

- **`runtime-endpoints.json`**: Карта портов и адресов локальных сервисов (API, MCP, Qdrant, UI).
- **`retention-policy.json`**: Политика удержания и ротации записей памяти по категориям.
- **`mcp-registration.json`**: Реестр и декларация групп MCP-инструментов.
- **`context-profiles.json`**: Профили лимитов токенов и правил форматирования контекста.
- **`security-scan-local-llm.json`**: Правила и шаблоны сканирования секретов local security gate.
- **`project-registry.json`**: Реестр зарегистрированных локальных проектов.

---

## 3. Защита секретов и локальных данных

> [!CAUTION]
> Никогда не добавляйте в Git файлы `.env`, базы данных `.db`, логи работы, ключи доступа и файлы с локальными путями.

Все приватные данные и локальные переопределения автоматически игнорируются через `.gitignore`:
- Файлы локальных настроек: `.env`, `.env.local`, `.local/`
- База данных и рантайм: `.runtime/`, `*.db`, `*.sqlite`, `*.wal`
- Кэш и логи: `.pytest_cache/`, `.ruff_cache/`, `*.log`
