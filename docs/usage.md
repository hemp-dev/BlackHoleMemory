# Руководство по использованию BlackHoleMemory

BlackHoleMemory (BHM) предоставляет долговременную память для AI-агентов. Ниже описаны основные сценарии использования, паттерны работы и примеры взаимодействия.

---

## 1. Базовый сценарий: Передача контекста между сессиями

В обычном режиме при завершении сессии в чате AI теряет контекст работы. BHM позволяет сохранять ключевые факты и решения:

1. **Предполётная проверка контекста (Preflight)**:
   При старте работы агент вызывает `bhm_preflight` или `bhm_context_compile` для получения агрегированного контекста по текущему проекту.

2. **Запись открытой задачи**:
   Агент открывает сессионный контекст с помощью `bhm_task_open(task_id="WI-102", title="Рефакторинг слоя БД")`.

3. **Сохранение принятых решений**:
   При принятии важных архитектурных решений агент сохраняет их через `bhm_adr_create` или `bhm_upsert_memory(category="architecture")`.

4. **Закрытие задачи и чекпоинт**:
   По завершении работы агент фиксирует чекпоинт через `bhm_checkpoint_create` и закрывает задачу `bhm_task_close`.

---

## 2. Сценарий: Анализ рисков изменений (Change Impact)

Перед внесением сложных правок в существующий код агент запрашивает оценку рисков:

1. Вызов MCP-инструмента `bhm_change_impact(target_files=["src/blackholememory/memory_repository.py"])`.
2. BHM исследует граф зависимостей кода и возвращает список затрагиваемых модулей, тестов и потенциальных точек отказа.
3. Агент строит безопасный план изменений без нарушения контрактов сторонних компонентов.

---

## 3. Сценарий: Принцип Proposal-Only и безопасность

Все операции, предполагающие модификацию кода или конфигураций:
- Генерируют **план/proposal** в виде структурированного описания (diff/proposal);
- Требуют явного подтверждения оператора перед применением;
- Гарантируют невозможность несанкционированного удаления данных.

Для безопасного управления памятью используйте двухэтапную процедуру:
1. `bhm_forget_preview` — просмотр списка записей, подлежащих очистке;
2. `bhm_forget_apply` — явное применение плана (требует прав администратора).

---

## 4. Сценарий: Визуальный анализ в Galaxy UI

Для оператора доступен 3D/2D граф связей в веб-интерфейсе:
- Перейдите по адресу `http://127.0.0.1:8000/bhm/galaxy`;
- Исследуйте узлы концептов, кластеры задач и связи элементов кода в реальном времени;
- Выполняйте интерактивный поиск и фильтрацию по категориальным тегам.
