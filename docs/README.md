# Документация BlackHoleMemory

Добро пожаловать в официальную документацию **BlackHoleMemory (BHM)** — локальной изолированной системы долговременной памяти для AI-агентов.

### 1. Пользовательские руководства

- **[Использование](usage.md)** — Основные сценарии взаимодействия, принцип proposal-only, работа с сессиями и Galaxy UI.
- **[Конфигурация](configuration.md)** — Переменные окружения, профили контекста, манифесты `config/` и безопасность секретов.
